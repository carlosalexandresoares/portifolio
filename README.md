# Portfólio de Carlos Alexandre

Site estático de apresentação pessoal, projetos e contato. Desenvolvido com HTML, CSS e JavaScript, sem etapa de compilação.

## Abrir localmente

Abra `index.html` no navegador. Para servir por HTTP, execute `python -m http.server 8000` nesta pasta e acesse `http://localhost:8000`.

## Conteúdo

Os projetos Purpverse e Folha foram descritos com base nos respectivos repositórios públicos. As imagens de GymControl e Cadastro de Usuários estão em `img/`. Os links de contato vieram do perfil público do GitHub de Carlos.

O layout funciona em telas pequenas e grandes. O menu móvel usa JavaScript; as demais seções e links funcionam sem ele.
